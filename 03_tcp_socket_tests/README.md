# TCP Socket Tests

Автотесты для десктоп-приложения, которое получает сигналы от удалённого сервиса через TCP-сокет.

## Что тестируется

Критический сценарий: **установка TCP-соединения с сервисом и получение данных**.

Без соединения приложение бесполезно — таблица сигналов пуста, кнопки не работают. Это точка входа для всех остальных функций.

## Покрытые сценарии

| # | Тест | Что проверяет |
|---|------|---------------|
| 1 | `test_connection_established` | TCP-соединение с портом 2001 |
| 2 | `test_data_received` | Сервис вернул непустой ответ |
| 3 | `test_signals_count` | Ровно 10 сигналов (по ТЗ) |
| 4 | `test_signal_structure` | Поля: ID, имя, значение, качество, время |
| 5 | `test_values_change_over_time` | Значения обновляются между запросами |
| 6 | `test_connection_closed_gracefully` | Корректное закрытие соединения |

## Стек

- Python 3.12
- pytest
- socket, threading, json
- Сервис-симулятор на порту 2001
